# 财问画像数据库

数据库独立存放在 `data/portrait/portrait.db`，不修改聊天、知识库或账号存储。
已实现存储基础、成绩批量写入、账号绑定校验、备份及只读画像页面。
页面入口为 `/portrait/overview`，提供学业表现、课程、在校信息、雷达图、
标签云以及日期/学期看板。尚未提供 Excel 导入页面、聚类执行或 AI 建议。
没有迁入朋友项目的演示数据或明文密码。

## 初始化与部署

```powershell
.\.venv\Scripts\python.exe -m deeptutor.portrait
# 在测试目录或其他路径初始化
.\.venv\Scripts\python.exe -m deeptutor.portrait --db E:\data\portrait.db
```

源码和 schema.sql 通过 Git 同步，数据库文件不提交。新电脑执行初始化
即可建立同样的表结构；搬迁正式数据则单独转移备份，不能依赖 git pull。
schema.sql、daily.sql 已加入 Python 包数据，安装包也会携带建表文件。

初始化是事务性的，可重复执行而不覆盖已有记录。PRAGMA user_version
记录结构版本，遇到未知版本或非空且没有版本的数据库会拒绝初始化。
将来升级必须添加明确的迁移，不能直接修改正式数据库版本标记。
当前采用 SQLite WAL、10 秒锁等待，每个连接启用外键；事务失败整批回滚。
数据库放在单台服务器的本地持久磁盘，不放网络共享文件系统。
当前结构版本为 2；版本 1 会事务性升级并保留原数据。只读 API 首次使用时
执行初始化检查，也可在部署时先显式运行初始化。

## 表的分工

| 部分 | 表 | 作用 |
| --- | --- | --- |
| 组织与时间 | colleges、majors、classes、semesters | 学院、专业、班级、真实学期 |
| 人员 | students、teachers | 学号、工号唯一，基本档案 |
| 历史班级 | student_class_enrollments | 每位学生每学期所属班级，不用当前班级覆盖历史 |
| 教师范围 | teacher_classes | 教师、班级、学期多对多关联 |
| 财问账号 | account_bindings | 稳定 user_id 与学生或教师档案一对一绑定，不保存密码 |
| 课程与成绩 | courses、grade_records | 课程代码唯一，成绩保留学期和考试次数 |
| 行为 | behavior_records | 每位学生每学期一份汇总，记录来源、单位与量纲 |
| 日常记录 | daily_behavior | 学生、日期唯一；真实日期、上课/出勤节数、每日时长 |
| 导入与追溯 | import_batches、grade_changes | 批次统计，成绩修正前后值 |
| 标签 | tag_definitions、student_tag_values、class_tag_values | 定义与每批次结果分离 |
| 分析 | analysis_runs、cluster_tasks、cluster_results | 计算批次、聚类参数、分组结果 |
| 数据版本 | portrait_meta | 源数据变化后使旧画像退出当前视图 |
| 演示标记 | demo_datasets | 记录合成数据生成批次，防止重复生成 |

共 23 张表，另有两个当前标签视图。内部关联有外键保护，删除默认受限，
不会因为误删学生就连带清空历史成绩。常用过滤字段建索引。

## 账号边界

财问账号仍保存在现有 JSON 身份存储中；SQLite 不可能给外部 JSON 建外键。
bind_account() 会检查账号存在、已激活、为普通成员，且学生/教师身份匹配。
管理员与最高管理员无需绑定学生或教师档案。
HTTP 查询接口已按当前账号、teacher_classes 和学期过滤，学生只能查询自身
绑定档案；管理员查看全部，教师仅查看所分配班级。数据库本身不提供行级权限。
账号删除、身份改变后的绑定维护和批量师生档案导入尚需在业务接口阶段接入。
不能仅根据 account_bindings 的历史内容认定当前账号仍具备访问资格。

## 成绩导入

import_grades() 接收结构化记录，不读取或执行外部 SQL 文件。调用者需提供
student_no、course_code、semester_code、score，可提供 attempt_no、status。
先建立基础档案、学期与课程；这里不会按姓名匹配或猜测缺失的引用。

- 业务唯一键为学生、课程、学期、考试次数；默认次数为 1。
- 同样的记录再次导入会跳过，不增加成绩记录。
- 已有成绩被更正时保留原主键，记录修正前后值和来源批次。
- 一批中同一业务键出现互相矛盾的成绩，整批拒绝。
- 任意一行非法，成绩、追溯、批次记录一起回滚；异常包含行号。
- 正常成绩必须有数值且在课程满分以内；缺考、免修、待录入使用状态和 NULL。
- 写入层不擅自选择最高分或最新补考成绩。

其他表目前依赖唯一约束阻止重复写入；对应的 Excel 导入服务尚未实现，
不能将成绩导入方法描述为已支持所有类型文件。

## 行为与标签

考勤率使用 0 到 100；学习、睡眠、上网时长明确为平均每日小时数，允许
0 到 24。课堂参与度必须同时提供数值及满分尺度（5、10 或 100），不得猜测
旧表中 3 到 9 的值属于哪一种。社会活动必须同时指定数值、单位（次数/小时/评分）
和周期（周/月/学期）。无法确定含义时暂不导入，不能默认为正确口径。
NULL 表示未采集，0 表示已记录为零；两者不混淆。

只初始化 16 个学生、5 个班级标签定义，全部为草稿，没有生成虚构的画像。
为对照旧系统保留了“睡眠质量”的标签名，但目前只有时长，后续应按
睡眠时长分档解释或更名，不能声称测量了真实睡眠质量。
当前只读页面使用首次考试成绩；GPA 暂按原项目分段换算后的算术平均，
不按学分加权。非百分制成绩先归一为百分制。通过学分按通过课程学分求和。
当前标签云即时生成 7 类统计/分档标签，字号权重固定；不冒充已经实现全部
21 个标签定义或原来的完整规则引擎。React/CSS 排列标签无需新增依赖。
雷达图采用统一固定尺度，展示行为与成绩，不能将其面积解释为综合能力。
问卷、心理量表标签和运动天数不建字段，不做导入。

结果按批次留存，缺失与异常使用显式状态，不填成零。源成绩、行为、课程、
班级档案或规则发生写入后递增数据版本。current_student_tag_values 和
current_class_tag_values 只展示同版本、成功完成的最近结果；历史结果保留。
将来的页面不能直接读取历史结果表后把旧画像当成当前画像。

## 合成数据与看板

```powershell
.\.venv\Scripts\python.exe -m deeptutor.portrait.demo
```

仅适用于空画像库。固定种子生成 90 名学生、10 名教师、10 个班级、6 门课程、
2 个学期、1080 条成绩、180 条学期行为汇总和 5400 条日记录。
所有姓名、学号和页面均标明演示；不创建财问登录账号，不使用真实师生信息。
同批次重跑不会增加记录；已有非演示基础数据的数据库拒绝生成。
数据库数据文件不随 Git 同步，另一台开发机需自己运行此命令。

日期看板按所选学期最近 7/30 个有记录的日期展示，不伪造缺失日期；
日期出勤率为总出勤节数除以总应到节数，无课日为空。
学期看板展示有权限查看的各学期汇总，班级口径为当学期班级成员；
学期出勤为已有学生汇总率的均值。日常时长单位统一为小时/日。
学生和教师档案需绑定现有财问账号才可从普通成员入口查看。

如需创建真实的演示登录账号，在已有管理员和上述演示数据的本地实例运行：

```powershell
.\.venv\Scripts\python.exe -m deeptutor.portrait.demo_accounts
```

按提示输入初始密码。创建 `stu001`–`stu090` 和 `tea001`–`tea010`，
均为已启用普通成员，并按编号绑定对应学生/教师档案；各密码使用独立 bcrypt 盐。
脚本先备份账号文件和 SQLite，再创建账号；完整重复执行跳过现有正确绑定，
不会重置密码。若已有同名但关联不符的账号或档案被其他账号占用，预检查整批拒绝。
账号和画像位于两种存储中，异常中断应核对已完成记录及备份，不提供跨存储自动回滚。
这些真实账号仅供开发演示，上线前应更换测试密码或停用。

管理页显示姓名、学号/工号和班级关联，支持检索、状态筛选及 10/20/50 条分页。
档案关联接口 `/api/v1/portrait/account-links` 仅管理员可调用。
页面表面与图表颜色跟随六种现有主题，无新增前端依赖。

## 备份与验证

使用 PortraitDatabase.backup(destination) 做 SQLite 一致性快照，包含已提交的
WAL 数据，拒绝覆盖已有文件。不要只复制正在使用的 portrait.db 主文件。
恢复时停止画像写入，再将已验证备份恢复到目标路径；本轮提供备份，不提供
自动恢复或一键撤销某个导入批次的工具。

```powershell
.\.venv\Scripts\python.exe -m pytest tests/portrait -q
.\.venv\Scripts\python.exe -m deeptutor.portrait
```

测试覆盖幂等导入、成绩修正、非法值整批回滚、外键、单位、账号绑定、
并发重复写入、备份、结构版本保护及旧画像失效。这些不是几百用户容量压测。
