# 财问表情球 · 分层重构版

9 表情原型。南财红球体 + 自转经纬线，眼睛贴在球面上、会跟着鼠标在球体上转动。
身形用连续调和形变（默认为完美正圆），眼睛支持左右独立的眼形与尺寸（大小眼、眯眼、圆点眼）。

本仓库内的实现为**财问项目独立原创**，用于软著申报不存在第三方 IP 风险（见下方「借鉴边界」）。

## 跑起来

```bash
# 预览（必须用 http 协议，ES Module 不支持 file://）
python -m http.server 8765 --bind 127.0.0.1
# 打开 http://127.0.0.1:8765/

# 单元测试（Node 内置 runner，不需要装任何依赖）
node --test
```

## 分层

| 文件 | 职责 | 依赖 DOM |
|---|---|---|
| `src/math.js` | 缓动、帧率无关插值、弹簧、Catmull-Rom 路径平滑 | 否 |
| `src/shape.js` | 调和形变球身（`sphereSilhouette`）+ `radiusAt`（旧圆包络实现保留备用） | 否 |
| `src/face.js` | 球面投影（yaw/pitch → 屏幕坐标 + 透视压缩 + 背面剔除）、轮廓约束 | 否 |
| `src/states.js` | 9 个表情的纯数据配置 + 对外字段契约（含 eyeL/eyeR 单眼覆盖） | 否 |
| `src/typeline.js` | 打字机提示文字（React Bits `TextType` 的原生移植版） | 是 |
| `src/engine.js` | 建 SVG、每帧推进状态、抛事件 | 是 |

前四层不碰 DOM，所以能被 Node 直接 import 做测试——这是这次重构最主要的收益。

## 借鉴边界

工程做法参考了两个仓库，**但只参考到思路层面**：

- `jeremy-prt/bloub`（MIT）：分层方式（math / shape / face / states / engine 各司其职）、
  把眼睛放在球面坐标上做切向压缩、左右眼独立的眼形/尺寸表达力。
  **未使用其任何测量数据或状态参数**——那是它逐帧复刻 x.ai Grok 头像的产物，
  其 README 明确写着 MIT 不覆盖被模仿的设计，碰了就是把第三方 IP 风险带进财问。
- `sam70361/aora-bot`（自制许可）：emotionId 分段契约、`setEmotion` / `on('change'|'error')`
  的 API 形态、未知 ID 自动回退待机。其代码受「禁止商用」约束，**一行未用**。

## emotionId 契约

```
00-09  生命周期     00 睡眠 · 01 待机 · 02 欢迎
10-19  代理工作状态  10 思考中 · 11 检索中 · 12 回答中
20-29  结果反馈     20 完成 · 21 出错 · 22 惊讶
30-49  预留
50+    自定义
```

编号只增不改，对接方可以硬编码。

## 待机的完整节奏（01）

```
0.0s    待机（呼吸 · 眼神游移 · 单双眨交替）
5.0s    形变轮播：饼 → 六角 → 三角（各停 1s，收尾 0.45s 变回球）
9.8s    变形结束，缓冲 0.8s
10.25s  开始打盹（0.35s 缓入）→ 眼睛闭成线（低眼位、右眼略高、线向右上挑）
12.25s  开始苏醒（0.35s 缓出）：闭眼线淡出的同时 normal 眼形以压扁胶囊出现、
        随 open 爬回 1 逐渐"鼓"成全开——眼睛从一条线膨胀成一颗眼
12.6s   周期结束，回到待机 → 循环
```

顺序是**先变形、再睡**——打盹窗排在形变轮播之后（`morph.nap.at` 是"变形结束后多久开始睡"）。

打盹**不是**切表情，而是在待机姿态与睡眠姿态之间做连续插值，
所以进出都平滑、切走表情或形变开始会自然中断，也不会重播入场动画。

相位按 `morphTimeline(m).total` **取模**定位，所以每一轮都会打盹。
（曾经用绝对时间算窗，结果只有第一轮睡——`tests/engine.smoke.test.js` 专门盯这个回归。）

## 接入

```js
import { create } from './src/engine.js';
const ball = create(document.getElementById('slot'));
ball.setEmotion('11');                       // 未知 ID 自动回退 '01'
ball.on('change', (e) => console.log(e.id));
ball.destroy();
```

所有实例共享同一个 rAF 心跳，实例数量不增加循环开销。
